## 刊首语

苹果发布会结束，最热闹的话题不是芯片参数，而是「M4 MacBook Air 起售价降到 7999 元」。评论区立刻分成两派：一边喊「真香」，一边问「我去年刚买的 M3 是不是被背刺了」。

我想说的是：发布会是给「想换机的人」看的，不是给「需要换机的人」看的。真正该问的问题只有一个——你手头的设备，现在哪里让你难受？如果答案是没有，那再香的价格也和你无关。

五一假期也到了。这周我们聊换机判断、TypeScript 6.0、五一档电影，以及一个很容易被忽略但极加分的能力：代码审查。

本期所有内容，最后都指向同一个动作——先想清楚「我缺什么」，再决定「我要什么」。这也是我们想陪你练成的一种肌肉记忆。

祝大家假期快乐，也祝你玩得明白、休息得踏实、回来时带着一点新想法。

我们下周见。

——《青年周刊》编辑部

## 科技新势力

> 别让「发布会的参数」替你做决定，让「你真实的需求」做决定。

### M4 MacBook Air 降价 1000 元，但先问你的旧机哪里不够用

M4 MacBook Air 把 CPU 提到 10 核、最高内存 32GB、续航 22 小时，起售价反而降了 1000 元，还支持双外接显示器。

对谁值得换：旧机是 Intel 芯片、或内存 8GB 已经明显卡顿的人。对 M 系列近两代用户，性能差异在日常办公里几乎感知不到，换机更多是「情绪价值」。

行动建议：把换机的钱先按住，列一张「旧机让我难受的三个场景」。列不满三条，就先不换。

### TypeScript 6.0：模式匹配来了，但大版本要留测试时间

TypeScript 6.0 带来更准的类型推断、更顺的模式匹配语法和独立的类型声明写法。

我的态度和上次聊 Python 一样：个人项目可以先尝鲜，团队项目留足测试时间。类型系统升级最麻烦的不是新语法，而是「第三方库的类型还没跟上」，这会导致一堆莫名其妙的报错。

行动建议：先在一个小项目里试 6.0，把你遇到的类型报错和库兼容问题记下来，这就是你评估升级成本的依据。

### 前端工具链一周更新：追「新」不如追「稳」

Vite 6 启动更快、Next.js 16 稳定了 Server Components、Bun 2 号称 npm 兼容 100%、pnpm 10 安装提速。

面对密集更新，正确的姿态是：让它们飞一会儿。工具链的价值在「稳定可依赖」，不在「抢先」。等一个版本发布了 1-2 个补丁、社区把坑踩完，再跟进也不迟。

行动建议：只挑一个「能立刻解决你当前痛点」的更新去试，其余的先记在清单里观望。

### Claude App 记忆功能：AI 记住你，也请你管理它

Claude App 新增记忆功能，可以跨对话记住你的偏好、整合个人知识库，并且支持查看和删除记忆。

便利的另一面是：你喂给它的信息越多，越要清楚「它记得什么、能删什么」。把记忆当「会出错的助手笔记」，而不是「绝对准确的档案」。

行动建议：打开一次记忆管理页，看它都记了些什么，把不需要的删掉，顺便想想「我到底愿不愿意让它长期记住这件事」。

## 二次元次元壁

> 四月番陆续收官，该给这季一个总结了。

### 四月新番完结评价：霸权与遗憾都写在口碑里

这季收官，口碑基本定型：

- 《迷宫饭》9.9 分收官，稳坐本季最佳，把「美食 + 生存哲学」的路走到了极致；
- 《葬送的芙莉莲》S2 9.8，情感浓度拉满，是「安静但后劲足」的代表；
- 《胆大党》9.5，从黑马跑成真霸权，荒诞设定下的认真劲儿赢了。

也有遗憾：《暗杀巨人》第二季结局仓促、《物理魔法使》S2 质量下滑。这再次说明：开播热度不说明什么，收官的完成度才是真本事。

### 《蔚蓝》十周年：抑郁症主题的深刻表达

经典独立游戏《蔚蓝》迎来十周年，官方免费赠送原版，还宣布了《蔚蓝2》。

它十年不褪色的原因，是把「抑郁」这个沉重的主题做进了平台跳跃的机制里：登山的过程就是与自己的情绪搏斗，每一次跳跃都是一个小小的坚持。好的表达，从不喊口号，而是让你「亲身体会」。

行动建议：哪怕不玩游戏，也值得看一遍它的开发幕后纪录片，理解「把抽象情绪做成具体体验」是怎么做到的。

### 漫画推荐：《胆大党》的「骰运」设定

《胆大党》漫画的设定是：一个用骰子决定家庭决策的奇特家庭，每个角色都有自己独特的「骰运」。

它反套路的地方在于：不靠「天降奇迹」解决冲突，而是让角色在荒诞规则里认真生活。荒诞 + 认真，正是它能同时做到「好笑」和「好哭」的原因。

### AI 同人图：工具好用，边界要想清楚

AI 生成同人图越来越方便，但围绕它的争议集中在两点：训练数据的版权，以及「喂某个画师作品生成仿作」是否越界。

我的看法：把 AI 当「灵感草稿」和「风格参考」可以，但别把「模仿某位在世的画师」当成理所当然。技术让复制变容易，正说明「尊重原创」更需要自觉。

行动建议：用 AI 做同人时，默认标注「AI 生成」，也尽量别指定「某位具体画师的风格」。

### 五一游戏推荐（续）：硬核单机还是多人联机

上周按「时间预算」选游戏，这次换一个维度——你想一个人沉浸，还是和朋友一起闹：

选游戏前先想清楚「我现在缺的是独处还是热闹」，答案会帮你筛掉一大半选项。

### 手游版本更新：四个大厂的新内容

这周手游集体更新：《原神》4.7 仆人·阿蕾奇诺登场、《崩坏：星穹铁道》2.2 黄泉上线、《绝区零》1.2 新邦布、《鸣潮》1.4 新角色椿。

面对「限时 up 池」的催促，最有效的防御仍是那句：你上次离开时想解决的问题，这次被解决了吗？没有，就只是 FOMO。

### 独立游戏节国产新作：期待之外，看「完成度」

独立游戏节上的国产作品格外抢眼：《黑神话：悟空》万众期待，《昭和米国物语》脑洞清奇，《明末：渊虚之羽》是魂 Like 新尝试。

对任何「还在开发中」的作品，判断标准只有一个：能玩到的那部分，完成度如何。预告片可以剪，demo 骗不了人。

### 只玩手游的人，值得试的两款 PC 独立游戏

如果你平时只玩手游，想趁假期试试 PC 独立游戏，推荐两款「低门槛、高回报」的：

- 《吸血鬼幸存者》：一局 15 分钟，上手 30 秒，用极简操作做出成瘾循环，是「爽感设计」的教科书；
- 《星露谷物语》：种田、钓鱼、社交，节奏舒缓，适合想「慢下来」的假期。

行动建议：用 Steam 的退款机制（两小时内可退）当「试玩时间」，不合适就退，零成本。

## 青春故事会

> 代码审查不是挑刺，是「互相让代码变好」的协作。

### 代码审查的艺术：审查者与作者的两份修养

代码审查（Code Review）是团队协作的关键环节，但很多人把它做成了「挑刺大会」。

作为审查者，记住三件事：

- 先肯定再建议：「这段逻辑很清晰，不过可以用 X 简化」比「这里写错了」更容易被接受；
- 用提问代替命令：问「这里的目的是什么」，而不是「改成 Y」；
- 分轻重：安全漏洞、性能问题必须提，代码风格之争适可而止。

作为作者，也记住三件事：提交前先自检、PR 描述写清「为什么这么改」、准备好解释自己的选择。

### 读者投稿：如何培养代码品味

一位读者分享：代码品味决定了你能走多远。他的方法是三条：

- 多读优秀开源项目（React、Vue 的源码），学习别人的架构取舍；
- 写代码前先用自然语言把需求说清楚，再画数据结构；
- 不断重构——好代码是改出来的，不追求一步到位。

我补充一条：读源码时带着问题去读，比如「它是怎么处理边界的」，比泛泛地「通读」收获大得多。

### 下班后的恢复力：假期怎么休才真的「充到电」

假期最大的陷阱是「报复性熬夜 + 报复性刷剧」，结果放假比上班还累。

真正有效的休息，满足两个条件：一是「切换」——做和平时不同的事（运动、出门、见人）；二是「有边界」——明确哪几天完全放下工作，而不是「随时待命」。

行动建议：这个假期，给自己定一条「不碰工作消息」的时间段，哪怕只有一天，看看真正的放松是什么感觉。

### 给实习生的简历与面试建议

简历和面试的第一目标，不是「显得优秀」，而是「让对方快速看懂你能做什么」。

- 简历：用「动词 + 结果」写经历，比如「独立完成 XX，效率提升 30%」，比「参与 XX 项目」有信息量得多；
- 面试：准备三个「具体到细节」的项目故事，讲清「我遇到什么问题、我做了什么、结果如何」；
- 心态：把前几次面试当「练习局」，别把最想去的公司排在第一个。

行动建议：拿你的简历，把每一条「参与 XX」改写成「动词 + 结果」的版本。

## 好工具

> 工具在进化，但判断标准不变：它有没有帮你省掉真正烦人的部分。

### Cursor Agent Mode：从「补全」到「代理」

Cursor 的 Agent 模式进一步升级：能自动完成多文件修改、理解项目上下文、执行 git 操作、运行测试。

它的边界也很清楚：适合「目标明确、步骤机械」的活儿（修 bug、写测试、加文档），不适合「方向还没想清楚」的探索。把代理当「执行力很强的实习生」，你负责定方向，它负责执行。

行动建议：从 `/test`（为函数写测试）和 `/doc`（补文档）这类低风险命令开始，先建立信任，再放更多权限。

### VS Code Cloud：低配设备的救星

VS Code Cloud 把开发环境搬进浏览器，无需本地配置，还能和 GitHub Codespaces 打通。

它的最佳场景：临时环境、教学演示、低配设备、以及在别人电脑上「零安装」改代码。但它依赖网络，不是「离线主力机」的替代品。

行动建议：如果你常在多台设备间切换，或电脑配置吃紧，用 Codespaces 建一个项目试试，感受一下「环境跟着账号走」的省心。

### 假期出行 App：装这四个就够了

五一出行，四个 App 覆盖大部分场景：铁路 12306（购票）、高德地图（导航）、大众点评（吃饭）、飞猪（酒店机酒）。

更实用的建议是「提前下载离线地图 + 缓存行程」：节假日景区网络拥堵是常态，别把导航和票都押在「现场联网」上。

### AI 日记 App：记录生活，也回顾自己

AI 日记类应用（Day One、Reflect 等）在「记录」之外，多了「回顾与洞察」：帮你整理情绪、串联零散记录。

它们的价值不在「AI 替你总结得多漂亮」，而在「逼你持续记录」这件事本身。先养成每天三行的习惯，再谈 AI 洞察。

行动建议：假期结束前，写三条「这个假期最值得记住的瞬间」，不用多，但要具体。

## 在看什么

> 五一档和书单，都按「你想获得什么」来选。

### 五一档电影：合家欢还是特效大片

五一档院线，选片先问同行的有谁：

- 《哪吒之魔童闹海》：国漫标杆续作，适合全家一起看，期待值也最高；
- 《间谍过家家》：合家欢的稳妥选择，笑点密集；
- 《哥斯拉大战金刚2》：纯特效爽片，别带脑子，享受画面就行。

一个提醒：大档期电影口碑出得慢，可以等首波真实评价出来再买票，省得踩雷。

### 书籍：《思考，快与慢》：认识你的两个系统

卡尼曼把人的思考分成两个系统：系统 1 快速、直觉、情绪化；系统 2 缓慢、理性、费力。

读这本书最大的收获不是知识，而是「识别自己何时在被系统 1 牵着走」——冲动下单、锚定效应、损失厌恶，几乎每天都在发生。

行动建议：下次做「金额较大或不可逆」的决定前，强制自己睡一觉再定，给系统 2 一个上场的机会。

### 播客：《How I Built This》：创业故事的「去神话化」

《How I Built This》采访创始人，讲 Airbnb、Notion 等公司从零开始的故事。

它最难得的是「不神话」：创始人会坦诚讲失败、差点倒闭和运气成分。这比任何成功学都更接近真实——成功从来不是一条直线。

行动建议：挑一集你熟悉的公司，边听边记下「他们踩过哪些坑、怎么爬出来的」，比听「怎么成功的」有用得多。
