## 刊首语

这周有两件事让我停下来想了很久：一是 RTX 5090 发布，性能数字一个比一个吓人；二是 Sora 2.0 生成的高清视频，已经逼真到需要暂停确认「这是拍的吗」。

它们背后其实是同一个问题：当「更强」和「更真」都来得太快，我们该怎么保持判断力？显卡年年更新，但大多数人真正需要的，是把手上这台机器用到极限；AI 视频越来越真，但比「会不会被骗」更重要的，是「我还能不能相信自己的眼睛」。

恰逢地球日，这周我们也想聊聊科技和它的代价——不只是环保意义上的代价，更是我们注意力、判断力和钱包的代价。

所以本期的话题都围绕一个词：克制。买不买、玩什么、学什么，都先问一句「我真的需要吗」。

——《青年周刊》编辑部

## 科技新势力

> 参数很震撼，但震撼之后要问一句：对我意味着什么。

### RTX 5090 发布：性能翻倍，先问你要不要为它付电费

RTX 5090 用 Blackwell 架构把 CUDA 核心提到 24576 个、显存 32GB GDDR7、带宽 1.8TB/s，代价是 575W 的功耗——比上一代还高了 125W。

对谁值得买？只有两类人：跑本地大模型、做 Stable Diffusion 批量生成的 AI 开发者，以及追求 4K 高刷的硬核玩家。对大多数人，一张 5090 是「为用不到的算力付电费和溢价」。

行动建议：买显卡前先写一句「我要用它跑什么」。写不出来具体用途，就说明你不需要它，只是被参数撩到了。

### Sora 2.0：比「会不会被骗」更重要的是「谁来标注真实」

Sora 2.0 能生成 60 秒高清视频，角色一致性大幅提升，还能局部修改、精确控制镜头。

真正的变化不是「视频变多了」，而是「生成内容的成本低到人人可用」。这带来的新问题：当一段视频无法靠肉眼分辨真假，我们需要新的「可信机制」——水印、来源标注、平台审核，以及观众自己的怀疑习惯。

行动建议：从今天起，养成一个习惯——看到「过于完美」的现场视频，先查来源，再决定要不要相信和转发。

### Python 3.13：JIT 来了，但别急着升级生产环境

Python 3.13 带来了实验性 JIT、更快的启动速度和更友好的报错信息。

我的建议很明确：新项目可以尝鲜，生产环境继续留在 3.12 LTS。语言升级的收益，要等到你的依赖库全部兼容之后才真正兑现，而这个过程往往比你想象的长。

行动建议：开一个新分支，把一个小工具用 3.13 跑一遍测试，记录哪些依赖还没跟上，这就是你「何时能升级」的真实时间表。

### Rust 2024 Edition：语法更顺，但别为了「新」而迁移

Rust 2024 Edition 带来更友好的异步语法、改进的类型推断和标准库增强。

Edition 和普通版本号不一样：它保证「同版本内可混编」，迁移通常只是改配置加少量适配。但即便如此，也别为了追新而迁移——只有当新语法能真正简化你的代码时，收益才为正。

行动建议：把项目里最啰嗦的一处异步代码翻出来，看看 2024 语法能不能让它变短，再决定要不要升级。

## 二次元次元壁

> 三周之后再看新番，谁是黑马、谁在裸泳，已经能看出来了。

### 4月新番中期评价：热度会褪，口碑会留下来

开播三周，排行榜的泡沫基本挤掉了，剩下的靠口碑说话：

- 《迷宫饭》持续霸榜，B 站 9.8、豆瓣 9.4，用「美食」讲生存哲学的路子越走越稳；
- 《胆大党》从冷门冲到 9.5，是本季最大的黑马；
- 《夏日大作战2》靠情怀稳居前列，但「能不能超越前作」的讨论还在继续。

一个有用的观察：真正能打的作品，热度是「后来居上」的；靠营销冲高的，三周后就会现形。追番如此，追任何热门事物也一样。

### 《葬送的芙莉莲》第二季：用最少的台词讲最深的情感

这一季最动人的一场戏，是辛米尔与尤里的重逢——几乎没什么台词，全靠动作和留白。

这种「克制」是高级的表达：最浓的情感，往往在说不出口的地方。创作者敢留白，是因为相信观众能接住。

行动建议：如果你也在做内容（写作、视频、设计），试着删掉一个「解释过多」的地方，看看留白之后是否更有力量。

### 《胆大党》：荒诞设定里的认真劲儿

《胆大党》的设定很疯：靠掷骰子决定命运，荒诞又热血。

但它的黑马体质来自一个反差——设定越荒诞，人物越认真。每个角色都在认真地面对一个不讲道理的世界，这种「认真」让荒诞变得可信，也让爽感有了重量。

行动建议：下次评价一部作品（或一个产品），别停在「设定新不新」，多问一句：它有没有把设定「认真做到底」。

### 漫画推荐：《迷宫饭》原作的细节控

动画之外，《迷宫饭》漫画的原作细节更密：魔物的生态设定、料理的考据、角色心理的层层推进，都值得慢慢翻。

看原作和看动画的体验差异，本身就是一个有意思的媒介观察：动画用画面和节奏制造沉浸，漫画用分格和留白逼你慢下来。两者各有胜负。

行动建议：如果一部作品你只看过动画，挑它的原作翻一卷，感受一下「另一种讲法」。

## 游戏研究所

> 五一假期就在眼前，但选游戏要按「你有多少时间」，而不是「游戏多有名」。

### 五一假期游戏清单：先定时长预算，再挑游戏

假期选游戏最大的坑，是挑了需要 100 小时的 RPG，结果只玩了 3 小时就返工。

先按你的真实时间预算来选：

- 只有零碎时间 → 《吸血鬼幸存者》《哈迪斯2》：一局几分钟到十几分钟，随时能停；
- 有整块时间想沉浸 → 《博德之门3》《王国之泪》：需要长投入，但回报同样长；
- 只想放松不费脑 → 《动物森友会》：钓鱼、种花，纯粹的治愈。

行动建议：打开日历，先划出你假期「真正能玩游戏」的小时数，再回头选清单，而不是反过来。

### Steam 新品节：Valve 的免费小品与两部值得盯的新作

新品节又来了，先捡两个免费的：Valve 的《Aperture Desk Job》短小精悍，适合当开胃菜；《inZOI》被称为「韩国版模拟人生」；《Neva》是《Gris》团队新作，美术大概率在线。

判断一款 demo 值不值得花时间，标准还是那句：15 分钟内没让你产生「想继续」的冲动，就跳过。

### 手游速递：更新很热闹，回坑要问自己一句

这周《鸣潮》1.4、《原神》4.7 前瞻、《明日方舟》联动活动都来了。

面对「限时活动」「限定角色」的催促，最有效的防御是问一句：「我上次离开时想解决的问题，这次被解决了吗？」如果没有，热闹只是 FOMO（错失恐惧），不是理由。

### 独立游戏速递：看团队「上一部」，比看预告更准

《Neva》是《Gris》团队新作，美术大概率延续水彩治愈风；《inZOI》被叫「韩国版模拟人生」，主打写实生活模拟。

判断独立游戏最靠谱的方法，不是看预告片，而是看团队上一部作品完成度如何。风格会延续，执行力也不会凭空消失。

行动建议：对任何一款心动的独立游戏，先花 10 分钟查它团队的前作，再决定要不要加愿望单。

## 青春故事会

> 挫败感是正常的，关键是你怎么处理它。

### 如何克服编程学习的挫败感

每个程序员都经历过「我是不是不适合写代码」的时刻：第一行 Hello World 就报错、第一个项目全是 bug、第一次面试大脑空白。

走出低谷的四个方法：

- 接受挫败是常态——连火箭都要失败很多次，你的 bug 真的不算什么；
- 拆分问题——大目标拆成小目标，每次只解决一个；
- 记录进步——每周写学习日志，回看时会发现自己其实走了很远；
- 找到社区——和同路人交流，能极大减少「只有我不行」的孤独感。

行动建议：现在就写一条「我上周比上上周多会了什么」，越具体越好。

### 从学生到职场人：四种思维转变

| 学生思维 | 职场思维 |
|---------|---------|
| 追求标准答案 | 追求当前约束下的最优解 |
| 独自完成作业 | 与他人协作交付 |
| 按部就班学 | 自主驱动找问题 |
| 问题有人出好 | 自己定义问题 |

最核心的一条：职场没有「标准答案」，只有「在资源、时间、信息都有限的情况下，你选了什么、为什么选」。学会讲清楚你的选择逻辑，比找到唯一正确解更重要。

### 读者投稿：从给文档纠错开始的开源之路

一位读者分享：一年前开始参与开源，从给文档纠错起步，现在 PR 已经被合并进多个知名项目。

他的入门建议很朴素：从你已经在用的项目开始；从 `good first issue` 标签开始；先提文档和测试，再碰代码；别怕被拒绝——被 review 打回，本身就是学习。

行动建议：这周挑一个你常用的开源项目，读它的 CONTRIBUTING 指南，找一条 `good first issue`，哪怕只是修一个错别字。

### 给焦虑的应届生三条建议

临近毕业，焦虑很正常。三条实在的建议：

- 把「我找不到好工作」换成「我下一步能做什么」——焦虑来自模糊，行动能把它变成具体问题；
- 用「小步验证」代替「一步到位」：先投 10 家练手，再投目标公司，别把最想去的放在第一个；
- 接受「起步都普通」：多数人的第一份工作不是终点，而是帮你弄清「我适合什么」的样本。

行动建议：今天就列 5 家「练手公司」，把简历投出去，别让「完美简历」卡住你的第一步。

## 好工具

> 换工具之前，先想清楚自己到底要解决什么。

### Docker Desktop 收费了？试试这三个替代品

Docker Desktop 对大型组织收费后，个人和小团队可以看看替代品：

- OrbStack：轻量、启动快，体验最好，但仅限 macOS；
- Podman：无守护进程、更安全，但和部分工具兼容性稍差；
- Colima：主打 Docker 兼容，胜在省心。

选型的判断标准不是「哪个最火」，而是「哪个在你的系统上最不折腾」。工具的意义是解决问题，不是制造新的配置地狱。

### 笔记软件怎么选：先回答「本地优先还是协作优先」

四款主流笔记各有脾气：

- Obsidian：本地 Markdown、双向链接，适合长期积累、重视数据主权的人；
- Logseq：大纲式，适合喜欢「块」和日记流的人；
- Notion：全能但加载慢，适合团队和结构化项目管理；
- 飞书文档：团队协作顺手，但导出麻烦、数据在别人服务器上。

行动建议：别同时迁移四个。先想清楚一个场景——「我主要用来干嘛」，再选一款，用满一个月。

### 番茄钟 App：Forest 与 TickTick 的区别

- Forest：游戏化专注，种树有成就有约束力，还支持团队模式，适合需要「仪式感」管住手机的人；
- TickTick：番茄钟 + 待办 + 统计，适合想把专注和任务管理合一的人。

关键不是用什么 App，而是「25 分钟只做一件事」这个协议本身。App 只是帮你守住协议的闹钟。

### GitHub Actions AI 助手：把「构建失败」交给 AI 先看一遍

GitHub 推出的 AI 驱动 Actions，能自动修复失败的 CI/CD、智能生成工作流配置。

它的价值在于把「排查构建失败」这个最磨人的环节缩短：AI 先给一个初步判断，你再决定采纳还是深挖。别盲信它的修复，但把它当「第一道过滤」很划算。

行动建议：下一次 CI 失败时，先让 AI 助手看一眼报错，对照它的解释验证，再动手改。

## 在看什么

> 这周推荐一部烧脑剧、一本讲「背锅」的书、一档硬核播客。

### 剧集：《人生复本》：平行世界的代价

《人生复本》讲的是平行世界：每做一个选择，就分裂出一个「没选那条路」的自己。

它最扎心的不是科幻设定，而是一个追问：你愿意用现在的人生，去换「当年如果……就会更好」的那个版本吗？多数人幻想过，但剧集用最直白的方式告诉你——每个版本都有它的代价。

### 书籍：《设计心理学》：别让用户替你的设计背锅

诺曼的核心观点一句话就能概括：用户用不明白，多半不是用户笨，是设计没符合他的心理模型。

这本书值得所有「做东西给人用」的人读，不只是设计师。写文档、做 API、做 PPT，本质都是在设计「别人怎么理解你」。把责任从「用户」挪回「设计者」，很多冲突会自然消失。

### 播客：《硬核编程》：把难的东西讲透

《硬核编程》聊编译器、函数式编程、自建语言这类硬核话题。

它的价值在于「不简化，但讲得清」：真正的专业，是把复杂的东西讲到外行能听懂、内行挑不出错。这本身就是一种值得练习的能力。
