## 刊首语

这一周，Anthropic 宣布把 Claude Code 的「自动模式」设为默认开启——写代码这件事，正在从「人指挥机器」滑向「机器先动手，人做验收」。同一天，一家对冲基金给芯片初创公司投了 4 亿美元，另一家公司用 AI 满世界找新材料、做更省电的芯片。

「自动化」的临界点正在逼近：我们越来越习惯把重复的、繁琐的、甚至一部分「思考」交给机器。这当然能解放人，但也悄悄改变了一件事——我们正在把「控制权」一点点交出去。

在把方向盘交出去之前，也许值得先停下来问一句：哪些事该交给机器，哪些事必须牢牢握在自己手里？

这期没有标准答案，只有一条反复被验证的经验：自动化省下的时间，最好用来做那些「只能由你来做」的事，而不是用来刷更多让大脑停转的内容。

当然，自动化从来不是目的，而是手段——真正的目标，是让你腾出更多精力，去做那些机器做不了、也替代不了你的事。

——《青年周刊》编辑部

## 科技新势力

> 芯片、材料、代码与空中出行，本周的「自动化」信号。

### AI 打地鼠找芯片材料：Discovered Materials 融资 900 万美元

新材料公司 Discovered Materials 拿到 900 万美元，做的事很有意思：用 AI「打地鼠」式地筛选新材料，目标是造出更省电、散热更好的芯片。传统材料研发靠人猜、靠实验室慢慢试，现在交给 AI 在巨大空间里快速搜。

为什么值得关注？因为芯片的下一轮突破，可能不在设计，而在材料——更省电的晶体管、更高效的散热，都可能卡在「找不到合适的材料」上。AI 恰好擅长这种「在无数组合里找最优解」的活。

一句话洞察：当 AI 的算力瓶颈变成「材料瓶颈」，找材料就成了新的军备竞赛。

**试试看**：了解一个概念——「材料基因组」或「AI 辅助材料发现」，你会理解为什么「找材料」也能成为一门 AI 生意。

### 4 亿美元下注芯片：对冲基金还在押注算力

AI 主题的对冲基金 Situational Awareness 向芯片初创公司 Source Foundry 投了 4 亿美元。在市场对 AI 估值争议不断的时候，这笔钱传递了一个信号：头部资本仍然相信，算力是这轮 AI 的硬通货。

为什么值得你关心？因为「芯片」是 AI 链条上最确定的需求之一——无论大模型谁赢谁输，都要在芯片上跑。资本往这里下注，说明它赌的是「确定性的底座」，而不是「会讲故事的应用」。

一句话洞察：越是不确定的方向，越有人去押注最确定的那一环。

**试试看**：把「芯片设计、制造、材料」这条产业链画一画，标注每一环的代表公司，你会对 AI 的「底层」更有概念。

### Claude Code 默认开启「自动模式」：写代码开始不需要你盯着

Anthropic 宣布，Claude Code 的自动模式将默认开启——也就是说，AI 编程助手会更主动地帮你跑命令、改文件，需要的「人类监督」更少了。这是编程工具从「助手」走向「代理」的明确一步。

它高效，但也值得多想一层：当 AI 帮你做了大部分决定，你怎么保证「它做对了」？如果你看不懂它改了什么，出了问题又该怎么回退？自动化的前提，是你还保留着「验收」的能力。

一句话洞察：把活儿交出去容易，把「判断力」留在手里很难。

**试试看**：如果你用 AI 写代码，养成一个习惯——每一处 AI 改动，都先问自己一句「它为什么要这么做」，看不懂就不合入。

### 波音卖掉空中出租车业务：eVTOL 赛道重新洗牌

波音把旗下三家电动垂直起降（eVTOL）子公司卖给了 Archer Aviation，并入股后者。空中出租车这个曾经被热炒的方向，正在经历一轮整合——活下来的玩家开始抱团。

为什么值得关注？它说明「酷」的技术要变成「能跑通」的生意，中间隔着很长的路。eVTOL 的难点从来不只是造出能飞的机器，而是安全、监管、成本、航线一条条啃下来。整合，是赛道走向成熟的信号，也是淘汰赛的开始。

一句话洞察：长期技术比的不是谁先飞起来，而是谁能在漫长的落地期活下来。

**试试看**：如果你看好某个长期技术，别只看它炫不炫，去查它的「落地时间表」——安全认证、成本、基建，哪个最卡脖子。

## 好工具

> 把重复交给机器，把判断留给自己——本周四个「自动化」工具。

### 用 AI 编程助手写样板，你写判断

Claude Code 的自动模式上了新闻，但对大多数人来说，最实用的用法不是「全自动」，而是「半自动」：让 AI 写那些无聊的样板代码、补测试、改格式，而你只负责定义目标、审查结果。

关键是分工要清晰：机器擅长「按已知模式大量产出」，人擅长「判断什么是对的」。一旦你把「判断」也交出去，就会变成「看不懂自己代码」的尴尬局面。

一句话洞察：AI 帮你踩油门，但方向盘得留在你手里。

**试试看**：这周找一个你最近写的重复代码，让 AI 帮你重构或补测试，然后逐行审一遍它改了什么。

### 命令行三件套：alias、脚本、cron

如果你每天要敲同样的命令、做同样的操作，那你已经在浪费生命了。命令行三件套能解决 90% 的重复：alias 给长命令起短名，脚本把多步操作串起来，cron 让它们在固定时间自己跑。

它不需要你成为运维专家，只要求你「对自己的重复保持敏感」——一旦发现某件事你手动做了三次，就该考虑自动化它。省下的不只是几分钟，更是「切换注意力」的成本。

一句话洞察：自动化最大的收益，不是省时间，而是少打断思路。

**试试看**：找出你这周重复最多的一条命令或操作，用 alias 或脚本把它自动化。

### 把 AI 当「发散器」，而不是「答案机」

Discovered Materials 用 AI 找材料，本质上是把 AI 当「发散器」——在巨大空间里生成海量候选，再由人筛选。这个思路也适合日常：头脑风暴、列方案、想选题时，让 AI 先给 20 个可能性，你从中挑。

大多数人把 AI 用反了：问它「正确答案是什么」，然后全盘接受。更好的姿势是问「还有什么可能性」，再靠自己判断。前者让你变懒，后者让你变强。

一句话洞察：AI 最适合做的是「扩空间」，最危险的是替你「下结论」。

**试试看**：这周遇到一个需要创意的问题，先让 AI 给 20 个方向，你再从中筛出 3 个真正可行的。

### 通勤听播客：把碎片时间变成深度输入

这周 The Verge 的 Decoder 采访了 Bose CEO，聊音频、可穿戴设备和品牌授权。这类深度访谈，最适合在通勤、健身时「挂耳朵」——它不需要你盯屏幕，却能给你比刷信息流深得多的输入。

关键是「听完整的」，而不是「听三分钟切走」。一期 40 分钟的访谈，讲透一件事，胜过刷 40 条短视频。把碎片时间用来「听完一整期」，是一种被低估的自律。

一句话洞察：你的通勤时间，正在决定你和别人的信息差。

**试试看**：挑一期你领域里口碑好的播客，这周通勤时完整听完，并记下三个收获。

## 青春故事会

> 自动化时代，四个关于「掌控感」的成长命题。

### 程序员的新角色：从「写代码」到「审代码」

Claude Code 自动模式默认开启，最直接的冲击对象是程序员：当 AI 能写出大部分代码，你的价值正在从「写」转向「审」——审它的逻辑对不对、边界清不清、会不会埋雷。

这不是坏消息，而是一次升级。会写代码的人很多，能一眼看出「这段代码哪里会出问题」的人很少。后者的稀缺性，反而在 AI 时代被放大了。

一句话洞察：当「产出」被自动化，「判断」就成了最贵的技能。

**试试看**：练习「读代码找问题」——随便打开一个开源项目，试着在 10 分钟内找到一个潜在 bug 或设计问题。

### 把重复交给机器，把判断留给自己

这一期反复出现一个词：自动化。但自动化有个隐藏陷阱——如果你把所有事都交给机器，最后你会失去「判断这件事对不对」的能力。就像总用导航的人，渐渐记不住路。

聪明的做法是「分层」：重复的、可预测的，放心交给机器；模糊的、需要权衡的，必须自己上。这个分层能力，就是未来的核心竞争力。

一句话洞察：自动化的目的，不是让你变轻松，而是让你腾出脑子做更难的事。

**试试看**：把你一周的工作分成「可自动化」和「必须我来」两类，看能不能把第一类再压缩 20%。

### 「找材料」的启示：扩大搜索空间，而不是代替判断

Discovered Materials 用 AI 满世界找新材料，它的逻辑对个人成长同样适用：AI 的价值不是替你下结论，而是帮你把「可能性的空间」撑大，让你看到原本想不到的选项。

很多人的问题是「选项太少」——以为眼前只有 A、B 两条路。而 AI 能帮你列出 A 到 Z，虽然最后怎么选、选了之后怎么走，还得靠你自己。

一句话洞察：选择的质量，取决于你能看到多少选项。

**试试看**：用 AI 帮你列一列「你当前困境的 20 种可能解法」，哪怕大部分不靠谱，也可能藏着一条新路。

### 长期技术，需要长期主义的心态

eVTOL 赛道的整合提醒我们：再酷的技术，从「飞起来」到「规模化」也要很多年，中间还会有公司倒下、赛道洗牌。做长期方向的人，最需要的不是一时的热情，而是「熬得住」的耐心。

这给职业选择也提了个醒：如果你看好一个长期方向（AI、机器人、新能源），别指望一两年就见分晓。把眼光放到五到十年，你的很多焦虑会消失。

一句话洞察：看得远的人，不会被眼前的风吹草动晃倒。

**试试看**：写下你「五年后想成为什么样」，再倒推「今年该做的一件事」。

## 在看什么

> 一期访谈 + 一本书 + 一个科普方向，填满你的碎片时间。

### Decoder 访谈 Bose CEO：音频这门生意怎么做

The Verge 的 Decoder 采访了 Bose CEO Lila Snyder，聊这家 60 年老牌公司的转型：从卖音箱，到耳机、可穿戴设备、品牌授权，以及 AI 对音频的冲击。它不只是「耳机爱好者的节目」，更是一堂「老品牌如何不老化」的课。

为什么值得听？因为 Bose 面对的难题——技术迭代快、巨头竞争凶、品牌老化——几乎每个行业都在经历。看它怎么取舍，比看十个成功学故事都实在。

一句话洞察：老公司的对手从来不是新技术，而是「不肯变」的自己。

**试试看**：听完这期，想想你自己所在的行业，哪个「老玩家」正在被新技术逼着转型。

### 读《芯片战争》：看懂本周芯片新闻的前因后果

这周芯片材料、芯片融资的新闻扎堆，如果你一直对「半导体」这三个字似懂非懂，推荐去读《芯片战争》（Chip War，有中文版）。它把芯片几十年的历史、地缘博弈和产业链讲得清清楚楚。

这本书最厉害的地方，是让你从此看芯片新闻不再是「看热闹」——你会知道为什么一块芯片能牵动全球，为什么「先进制程」四个字值那么多钱。

一句话洞察：读懂一个产业的底层逻辑，胜过追一百条它的新闻。

**试试看**：先读前两章，建立起「芯片是怎么造出来的」基本框架，再回头看本周新闻。

### 空中出租车（eVTOL）科普：先搞懂它到底难在哪

波音卖 eVTOL、Archer 接盘，这条新闻背后是个很有意思的领域。如果你对「飞行汽车」有幻想，建议先去了解下 eVTOL 的三大难关：安全认证、续航成本、空域管理。任何一个，都比「造出能飞的机器」更难。

了解了这些，你再看各种「飞行汽车即将商用」的新闻，就会自动多一份冷静。

一句话洞察：炫酷的 Demo 和能用的产品之间，隔着监管、成本和基建三条河。

**试试看**：搜一篇关于 eVTOL 落地难点的科普，记住「最难的不是飞，是合规」。

## 谁在招人

> 本周融资与动向背后的三个方向信号。

### 芯片与材料：算力军备竞赛的「上游」在扩招

Discovered Materials 和 Source Foundry 的融资，指向同一个方向：芯片及其材料，正在成为 AI 时代最确定的「上游」。材料科学、芯片设计、工艺工程、设备制造，这些岗位的需求在稳步上升。

一句话洞察：当所有人挤向模型，上游的芯片和材料反而更缺人。

**试试看**：如果你有物理、化学、材料背景，去了解下「半导体材料」「芯片工艺」的岗位，可能是个被低估的交叉机会。

### 开发者工具：AI 编程正在催生一批新岗位

Claude Code 自动模式的背后，是一整个「AI 开发者工具」赛道在扩张。做 IDE 插件、做代码审查、做 Agent 框架的团队，都在招人。这个方向需要的不只是会写代码，更是「理解开发者工作流」的产品感。

一句话洞察：帮别人提效的工具，本身就是一个好赛道。

**试试看**：逛逛你常用的 AI 编程工具的官网，看看它们的「招聘」和「roadmap」，反推行业缺什么。

### 空中出行：eVTOL 整合期，活下来的玩家要扩张

Archer 接手波音的 eVTOL 业务，意味着它在整合后要扩充团队。航空工程、电池、自动驾驶、适航认证，这些方向都会跟着起来。虽然赛道还在早期，但「整合期」往往是最好的入场观察期。

一句话洞察：行业洗牌时，活下来的公司会加倍招人。

**试试看**：去 Archer 或同类 eVTOL 公司的招聘页看看，了解这个方向到底要什么背景的人。

### AI Agent 与自动化框架：把「自动动手」变成产品的团队在扩招

Claude Code 自动模式只是冰山一角，底下是一整个「AI Agent」浪潮——能自主规划、调用工具、完成任务的应用正在批量出现。做 Agent 框架、工作流编排、评测工具的团队，都在拼命招人。

一句话洞察：当「人写代码」开始变成「人指挥 AI 写代码」，指挥系统本身就成了新生意。

**试试看**：搜一搜「AI agent framework」或「workflow automation」的岗位，看看这个方向和你现在技能的匹配度。
