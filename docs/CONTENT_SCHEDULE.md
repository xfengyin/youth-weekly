## 3. 排期规则（deadline 约定）

1. **采集与策展**：发布周周五前完成（`make collect` → 人工策展，见 Runbook §3-①②）。
2. **初稿**：周五晚用 `scripts/draft_prompt.py` 生成提示词，AI 出初稿，负责人润色。
3. **审校**：周一中午前完成（`make weekly-check` + CONTENT_PLAYBOOK 质量关卡）。
4. **发布**：周一 21:00 自动发布（weekly-publish.yml）；若审校未完成，可手动推迟到周二补发。
5. **交接**：负责人请假时，由主编重新分配（替补顺序：创作者 A ↔ B ↔ C）。

- [ ] 周五前完成采集与策展（`make collect` + 人工筛条）
