## 1. 本期主题

**效率与基建：把工具链变成自己的生产力**

- 一句话角度：与其追新工具，不如把手上这套工具链打磨顺——本期聊终端、构建、本地模型
  与「可复制的配置」，重点是可照抄的流程与清单。
- 刊首语方向：效率不是「又装了一个新工具」，而是「把现有工具链的每一环都调顺」；
  本期想给三件「这周就能做完」的基建小事。

## 2. 板块规划（5 个板块，目标条目数）

| 板块 | 目标条目 | 内容方向 |
|------|:--------:|----------|
| 刊首语 | 1 | 「把工具链变成自己的生产力」：效率的三个层次（找工具 → 配工具 → 建流程） |
| 科技新势力 | 3-4 | 构建提速新方案、本地模型推理框架新进展、终端/开发环境新工具 |

| 在看什么 | 2 | 一本讲效率/工程文化的书、一档开发者播客 |

## 3. 目标条目与素材来源

- **自动化采集**（`make collect`，来自 `scripts/content_sources.yaml`）：
  - GitHub Trending：新开发工具/框架（`dev`/`oss` 分类）
  - Hacker News：构建/部署/本地模型高讨论条目（`tech` 分类）
  - arXiv CS：推理优化、编译器方向研究（`research` 分类）
- **人工补充**：
  - 团队真实使用的 dotfiles / 自动化脚本（好工具素材，需注明来源）
  - 工具链打磨的个人经验（青春故事会素材）
  - 书籍/播客推荐 1-2 条（在看什么，只写已确认存在的作品）
