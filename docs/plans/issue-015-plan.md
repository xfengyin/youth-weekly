## 1. 本期主题

**AI 应用落地：从尝鲜到干活**

- 一句话角度：AI 工具不再停留在「玩玩」——本期实测本地 4K 视频生成、AI 代码评审的真实数据，
  并给出把 AI 真正放进工作流的 3 个姿势。重点是「你现在就能试」。
- 刊首语方向：过去半年 AI 讨论从「能不能」转向「怎么用」；本期想聊的不是酷炫 demo，
  而是普通人/小团队本周就能落地的三件小事。

## 2. 板块规划（5 个板块，目标条目数）

| 板块 | 目标条目 | 内容方向 |
|------|:--------:|----------|
| 刊首语 | 1 | 「从尝鲜到干活」：AI 落地的三个层次（试玩 → 辅助 → 流程化） |
| 科技新势力 | 3-4 | 本地 4K 视频生成实测、AI 代码评审团队数据、强化学习设计火箭喷嘴、开源模型新进展 |
| 好工具 | 2-3 | 值得放进工作流的 3 个 AI 工具、终端/效率工具推荐 |
| 青春故事会 | 2-3 | 普通人用 AI 提效的真实经历、新手避坑清单（防幻觉/防过度依赖） |
| 在看什么 | 2 | 一本 AI 科普书、一档技术播客 |

## 3. 目标条目与素材来源

- **自动化采集**（`make collect`，来自 `scripts/content_sources.yaml`）：
  - Hacker News：AI 应用/工具高讨论条目（`tech` 分类）
  - GitHub Trending：新开源 AI 工具（`dev`/`oss` 分类）
  - arXiv CS：AI 应用研究（`research` 分类）
- **人工补充**：
  - 团队/身边人真实使用 AI 的案例（青春故事会素材）
  - 工具实测数据（本地跑通 4K 生成、AI 代码评审误报率等，需标注来源与日期）
  - 影视/书籍/播客推荐 1-2 条（在看什么）
